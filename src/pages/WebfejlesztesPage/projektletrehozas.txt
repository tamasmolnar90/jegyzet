##### node #####
################

node -v
npm -v
npm init (végig kérdez)
npm init -y (automatikusan elfogadja az összes alapbeállítást)
init: új node.js projektet indít

npm install express nodemon cors pg
express: legnépszerűbb node.js backend keret
nodemon: fejlesztéshez használt, automatikusan újra indítja a szervert
cors: cross-origin resource sharing (engedélyezi a böngészőnek, hogy React alkalmazásból hozzáférjen a backend API-hoz.)
pg: PostgreSQL klienskönyvtár node.js-hez (kapcsolódás az PostgreSQL adatbázishoz)

server.js (vagy index.js ritkábban) file létrehozása
